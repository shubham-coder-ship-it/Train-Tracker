# 🚆 Train Tracker

A modern, responsive Train Tracking web application built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. The application enables users to search trains, view train details, and access real-time train-related information through an intuitive and user-friendly interface.

---

## 📌 Features

- 🔍 Search trains by train number or name
- 🚉 View detailed train information
- 📍 Track train status
- 🗺️ Responsive and mobile-friendly UI
- ⚡ Fast performance with Vite
- 🎨 Modern interface built with Tailwind CSS
- 🔄 Client-side routing using React Router
- 🌐 REST API integration using Axios

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/TrainTracker.git
```

Go to project folder

```bash
cd TrainTracker/frontend
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
